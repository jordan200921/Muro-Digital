Frameset

El frameset es una estructura de HTML que

permite dividir la ventana del navegador

en varias áreasllamadas frames, donde se puede mostrar

un documento HTML difertente en cada área
Estructura
  • Cols: Divide la ventana en columnas verticales
  • Rows: Divide la ventana en filas horizontales
  • frame: representa cada área de la división
  • src: Indica que página HTML se mostrara dentro del frame
Iframe

permite incrustar una página o documento

HTML dentro de otra pagina web.

Su tamaño puede controlarse mediante atributos

como widht y height.

La estructura de este es de la siguiente manera:

<"iframe src=""contenido.HTML" widht="70%" height="400"><"iframe">
