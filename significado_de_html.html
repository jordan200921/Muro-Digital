DISEÑO Y DESARROLLO WEB

El diseño y desarrollo web es el proceso completo de creación, construcción y mantenimiento de un sitio web o una aplicación para internet. Este campo combina dos disciplinas diferentes pero que trabajan juntas: el diseño (la parte visual y la experiencia del usuario) y el desarrollo (la programación y la parte técnica).
