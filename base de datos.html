Qué es una base de datos

Es un conjunto organizado de datos que se almacenan de manera estructurada y de una misma caracteristica (empresas) para facilitar la consulta

tipos de software:
  • Oracle
  • My SQL
  • Postgre SQL
  • DB2
  • Acces
  • Exel
