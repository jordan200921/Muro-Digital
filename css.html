Qué es

CSS (cascading style sheets) significa hoja de estilos en cascada. Es un lenguaje utilzado para dar estilo y apariencia a los elementos HTML. En el diseño web se separan en diferentes funciones:

HTML: estructura y contenido

CSS: apariencia, diseño y distribucion.

CSS permite modificar colores, fuentes, tamaños

márgenes, posiciones y distribución

VENTAJAS
  • Permite separar la estructura HTML del diseño
  • Hace que el código se más obvio, faci y ordenado
  • Permite aplicar un mismo estilo a distintas páginas
  • Ofrece mucho control sobre la apariencia
  • Facilita la adaptacion de las pag a diferentes dispositivos
desventajas
  • puede tener una curva de aprendizaje dificil
  • navegadorespueden interpretar algunos estilos demanera diferente
  • La especialidad y herencia pueden generear conflictos entre reglas
  • Los diseños más complejos pueden requerir técnicas Avanzadas
